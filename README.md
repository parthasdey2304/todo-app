# Vastavik ToDo Ecosystem

Vastavik ToDo is a comprehensive, cross-platform task management ecosystem designed to keep your productivity seamlessly in sync across all your devices, no matter where you are. 

## 📱 Platforms

- **Android Native App**: A sleek, performant native Kotlin application built with Jetpack Compose for your primary mobile device.
- **Electron Desktop App**: A powerful desktop client built using Electron, Next.js, and TypeScript, giving you a fast, native-like experience on your personal laptop or PC.
- **Next.js Web App**: The core web client that powers the Electron app is also deployed to the web. This allows you to securely log in from *any* device (like a friend's phone or a public computer) and access your tasks without installing anything.

## ✨ Key Features

- **Omnipresent Sync**: Connected everywhere. Add a task on your phone, tick it off on your desktop, and see the changes instantly on the web.
- **Smooth & Premium UI**: Designed with fluid micro-animations, modern aesthetics, and a high-performance framework to ensure the user experience feels premium across all platforms.
- **Secure Authentication**: Built-in robust authentication ensures your private tasks remain securely locked to your account, allowing safe access even when using the web app from untrusted devices.

## 🛠 Tech Stack

- **Android**: Kotlin, Jetpack Compose
- **Web & Desktop**: Next.js (React), TypeScript, Electron.js
- **Backend**: Firebase (Authentication & Real-time Database)
